# Banking-Analytics

# Project Overview
This project is an interactive Banking Analytics Dashboard developed using Power BI to analyze banking operations and customer data. It provides insights into customers, transactions, loans, and customer support performance through multiple interactive dashboards.

# Dashboard Pages
- Overview Dashboard
- Customer Analysis
- Transaction Analysis
- Loan Analysis
- Customer Support Analysis

# Key KPIs
- Total Customers
- Total Balance
- Total Transactions
- Total Transaction Amount
- Total Loans
- Total Loan Amount
- Average Balance per Customer
- Loan Status Distribution
- Transaction Type Distribution
- Customer Support Resolution Rate

# Tools
- Power BI
- Power Query
- DAX

# Features
- Interactive slicers (Year, Transaction Type, Loan Type, Issue Type)
- KPI Cards
- Trend Analysis
- Geographic Analysis
- Customer Segmentation
- Loan Performance Analysis
- Transaction Analysis
- Customer Support Performance
